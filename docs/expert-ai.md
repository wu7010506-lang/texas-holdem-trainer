# Expert 策略設計與驗證

目標：維持六人牌桌與勝率的簡潔介面，五個對手都以長期盈利為決策目標。實際強度必須用測量描述，不能由策略名稱推論。

## 接口與資訊隔離

`buildBotContext(state, seat)` 是唯一實際牌局入口。新增自己目前下注、累積下注、公開對手座位與籌碼、已棄牌貢獻額；不傳送完整 PlayerState。動作紀錄逐欄列出，移除任意附帶欄位及可能包含暗牌的 reasoning，只保留公開盲注標記。

`ExpertTable.decide(context, styleIndex)` 對每個座位建立獨立 Worker。每個 Worker 只有自己的 ExpertStrategy 與 OpponentMemory，不能讀取其他 Worker 的牌或模型。牌局結束後僅同步公開動作；真實牌堆種子不傳入 Worker，策略使用獨立隨機來源。Node 測試使用同一策略實作，另給可重現的策略種子。

所有策略出口經 clampBotDecision，牌局引擎最後再次驗證。Worker request ID、牌局 ID、當前座位與 dispose 防止延遲動作套到新牌局；逾時會終止 Worker。移除原先的例外後自動棄牌降級流程。

## 決策

1. 翻前策略依位置、公開加注層級、跟注者、價格與有效籌碼設定頻率。CALL 是新增籌碼，RAISE / ALL_IN 是該街下注總額；不足跟注額的 ALL_IN 不算新的加注。
2. 對每個對手從所有與已知牌不衝突的組合開始，逐步乘上觀察動作的 likelihood。沒有行動資訊時不擅自排除隨機牌，所有動作保留低概率手牌，避免過度自信。該街牌面透過目前公牌的時間前綴重建。
3. 900 次 Monte Carlo 各自獨立提案全組對手牌，遇到碰撞整組重抽，獲得乘積權重在互不衝突條件下的分布。抽未來公牌自新標準牌組，與真實 deck 沒有關聯。
4. 同一批樣本比較所有候選動作，以 common random numbers 降低不同尺寸比較的噪聲。從當前牌面預測對手跟注 / 棄牌；單挑另抽樣再加注，自己對再加注的反應只依自己的目前牌與價格，不能根據抽樣的對手底牌或未來牌選動作。
5. 同時攤牌計算每個樣本真正贏家的 pot share；收益按下注分層計算，包含已棄牌籌碼、短籌碼、邊池和未跟注退款。以額外投入為成本，既有下注是沉沒成本。
6. 後續街使用權益實現折減，考慮位置、聽牌與多人；不完整展開所有未來下注樹。只在接近最高且非負收益的動作中混合，避免固定尺寸透露牌力。

公開行為記憶以 Beta 形式的先驗計數收縮，並設定最小樣本門檻及最大調整幅度。翻前與翻後的面對下注反應分開統計；翻前以位置和面對加注層級的預期棄牌率作參考，未開池的正常棄牌不計入面對加注的漏洞樣本。每次紀錄以手牌和索引去重；最多保留 80 手的去重與同步資料，累計統計仍存在當前 session。沒有跨頁面持久化。

## 驗證範圍

- 3,000 組可重現七張牌與 wheel、雙三條、四條、多張同花等案例，快速評估結果逐一對照原確定性 7 選 5 評估。
- 實際 context 更改其他座位底牌後保持相同；策略決策、Worker payload、移除下注理由及任意私密欄位均驗證。
- 翻前位置、ALL_IN 區分、範圍收縮、已知牌排除、四人 board tie = 1/4、主邊池及退款、河牌必勝價值下注、大額下注棄牌、五種風格的極端尺寸皆有回歸測試。
- Worker 舊 request ID、逾時與 dispose，以及實際 session 串行、重複操作、補籌碼均驗證。
- 六個 Expert 在真實 PokerGame 對戰，確認結束、合法動作和籌碼守恆。
- 長期基準用四個種子、六個 subject 座位、相同牌序對照 Expert 與原 TAG，其他五個對手是原 TAG / LAG / Calling Station / Nit / Maniac。每手重置 100BB，策略記憶保留。報告收益、配對差值與簡化常態 95% 區間；此區間未做 cluster correction，不能作為職業強度證明。
- 五高手桌另面對始終全押、反覆最小加注與從不棄牌三種公開攻擊，檢查每個動作與總籌碼；收益報告是樣本結果，沒有設定必須盈利才能通過的測試。

## 限制與後續工作

2026-10-03 交付版本的[原始基準結果](expert-benchmark.json)：四個種子、六個位置，Expert 與原 TAG 各 18,000 手。Expert 平均 +61.12 BB/100，原 TAG +22.07 BB/100，配對差值 +39.05 BB/100；簡化 95% 區間半寬 20.50 BB/100，非法動作 0。六個位置的 Expert 樣本收益皆為正，這是舊規則桌中的樣本優勢，不是對職業玩家的勝率。

五高手桌各面對 180 手始終全押、反覆最小加注與從不棄牌，共 540 手；攻擊方平均 -2294.67、-349.11、-781.17 BB/100。所有動作合法、籌碼守恆。前後半段使用不同牌，不能把收益差直接歸因於自適應；攻擊策略有限，尚不能證明沒有可利用的漏洞。

這不是完整求解器。對手 action likelihood、response policy 與 equity realization 都是估計；900 次抽樣存在噪聲，候選尺寸離散，沒有多人完整再加注樹，也沒有完整未來街策略。顯示給使用者的勝率仍是對隨機未知手牌的數學參考，與 Bot 自己推估的對手範圍不同。

沒有宣稱能打贏職業玩家。[Pluribus 原作者研究](https://noambrown.github.io/papers/19-Science-Superhuman.pdf) 使用自行訓練的策略及專業玩家實驗，這些工作不能由範圍啟發式的功能清單替代。下一步應採獨立樣本評估、增加強基準與針對策略漏洞的測試，再考慮離線策略訓練或求解器資料。

同時修正原引擎不足額全押錯誤開放加注權的缺陷。參考 [Poker TDA 的 Re-Opening the Bet 與累積短全押範例](https://www.pokertda.com/view-poker-tda-rules/)；以每個玩家的重新開放門檻判斷，保留最後完整加注額，新的 street 重設。
